# Журнал откликов

Журнал ведёт только `scripts/journal.py`, файл руками не правь. Скрипты запускай из папки навыка.

```bash
python3 scripts/journal.py add --company "…" --title "…" --url "…" --letter-file /tmp/letter.txt \
  --obj opening=опыт --obj number=да --obj story=нет --obj company=да --obj length=3-4 --obj tone=тёплый \
  --term FastAPI --term PostgreSQL
python3 scripts/journal.py outcome <id или часть названия компании> funnel|reject
python3 scripts/journal.py stats
python3 scripts/journal.py list
```

Повтор `add` с тем же текстом не создаёт дубль: скрипт ответит «уже записано».

- **Пользователь сообщил, какой вариант отправил** (например, «отправил 2») — сохрани текст этого варианта во временный файл и запиши его через `journal.py add` с объектами стиля и терминами. Если он правил текст перед отправкой, попроси финальный текст и заново определи объекты стиля.
- **Пользователь сообщил ответ рекрутера** («Cybersell — воронка», «отказ от Домклика») — запиши `journal.py outcome … funnel` или `… reject`. Скрипт сам обновит `style.md` в папке данных. Если компания подходит к нескольким письмам, скрипт выведет их список — спроси, какое имелось в виду.
- **Молчание не записывай.**
- До 15 исходов скрипт только копит статистику, стиль не меняется. Это нужно, потому что отказ часто вызван резюме, а не письмом, и на малом числе откликов счёт — случайный шум.
- Статистику по запросу показывай через `journal.py stats`.
